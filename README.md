# אתר תדמית לאדריכלית ומעצבת פנים

אתר תדמית מלא בעברית (RTL) עבור אדריכלית ומעצבת פנים, שנבנה ופורסם מקצה לקצה כפרויקט לימוד עצמאי בפיתוח Full Stack.
האתר משמש כתיק עבודות דיגיטלי: הצגת פרויקטים, שירותים ותהליך עבודה, ויצירת קשר ישירה עם לקוחות פוטנציאליים בוואטסאפ.

🔗 **האתר החי:** https://app.doyourbest.online

---

## מה האתר מציג

- **גלריית פרויקטים** עם סינון לפי קטגוריה וחלון פרטים לכל פרויקט
- **סליידר "לפני / אחרי"** אינטראקטיבי לגרירה
- **טופס יצירת קשר** שמפיק הודעה מוכנה בוואטסאפ
- **סליידר ראשי, מונים מונפשים והמלצות** מתחלפות
- **עיצוב רספונסיבי** שמתאים למחשב ולנייד, ותמיכה מלאה בעברית וכיוון מימין לשמאל

---

## מה בניתי ולמדתי בפרויקט

הפרויקט משמש גם כמסמך הניסיון המעשי שלי. התנסיתי בו בכל השרשרת, מהקוד ועד שרת חי:

### פיתוח Front-End
- **HTML5 סמנטי, CSS ו-JavaScript נקי (Vanilla JS)**, ללא פריימוורק, לצורך הבנה יסודית של הבסיס
- **מבנה נתונים נפרד מהלוגיקה:** כל התוכן בקובץ אחד (`data.js`) והממשק נבנה ממנו דינמית
- **תכנות מבוסס אירועים ו-DOM:** מודלים, סליידרים, מסננים ואנימציות
- **IntersectionObserver** לאנימציות גלילה, ו-**IndexedDB** לשמירת תמונות בדפדפן במצב עריכה
- **נגישות ו-SEO בסיסי:** `aria-label`, `lang="he" dir="rtl"`, תגיות meta וכיבוד `prefers-reduced-motion`
- **אינטגרציה עם WhatsApp** דרך `wa.me`, כולל קידוד טקסט בעברית ופירוק בעיות פורמט של מספרים בינלאומיים

### תשתית ו-DevOps
- **CI/CD מלא:** כל `git push` לענף `main` מפעיל פריסה אוטומטית לשרת חי
- **GitHub Actions:** כתיבת workflow בקובץ YAML, ניהול Secrets וקריאת לוגים
- **SSH ומפתחות קריפטוגרפיים (ed25519):** יצירת זוג מפתחות, התקנה בשרת, וחיבור ללא סיסמה
- **rsync:** העתקה חכמה של קבצים והתמודדות עם שגיאות הרשאות
- **שרת Linux עם CloudPanel:** משתמשי SSH, מבנה תיקיות, הרשאות כתיבה ותעודת SSL (Let's Encrypt)

### עבודה עם Git
- ריפו, ענפים, commits ו-remote, וכתיבת `.gitignore`
- הפרדת ריפו נפרד לכל פרויקט
- אבחון בעיות כמו `Repository not found` והתנגשות בין ריפואים

### אבחון ופתרון תקלות
- איתור סיבת שורש בעזרת חיפוש בקוד, בדיקות ידניות וקריאת לוגים
- פתרון בעיות מטמון דפדפן, הרשאות בשרת ושגיאות פריסה

## מבנה הפרויקט

```
web/
├── index.html      מבנה הדף
├── css/style.css   עיצוב
├── js/
│   ├── data.js     כל התוכן: טקסטים, פרויקטים, פרטי קשר
│   └── main.js     הלוגיקה והאינטראקציות
└── images/         תמונות הפרויקטים
.github/workflows/
└── deploy.yml      פריסה אוטומטית לשרת
```

---

## איך הפריסה עובדת

```
git push  →  GitHub Actions  →  rsync דרך SSH  →  שרת CloudPanel  →  האתר החי
```

1. דוחפים שינוי לענף `main`
2. GitHub Actions מתחבר לשרת עם מפתח SSH שמור כ-Secret
3. התוכן של `web/` מועתק לתיקיית האתר, ותוך כחצי דקה השינוי באוויר

---

## הרצה מקומית

האתר סטטי ולכן אין צורך בהתקנה. מספיק לפתוח את `web/index.html` בדפדפן, או להריץ שרת מקומי:

```bash
cd web
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000`.
