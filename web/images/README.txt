איך מוסיפים תמונות לאתר
========================
1. שמרי את התמונות בתיקיות הבאות (שמות הקבצים כפי שמופיעים ב-js/data.js):
   images/hero-1.jpg, hero-2.jpg, hero-3.jpg      - תמונות פתיחה (רחבות, 1920px)
   images/profile/shuli.jpg                       - תמונה שלך (לאורך, 4:5)
   images/projects/p1/1.jpg, 2.jpg ...            - תמונות לכל פרויקט (התמונה הראשונה = שער)
   images/before-after/before.jpg, after.jpg      - לפני / אחרי (אותה זווית צילום)
2. פרויקט חדש: ב-js/data.js להעתיק בלוק פרויקט קיים, לשנות id/כותרת/טקסטים,
   וליצור תיקייה images/projects/<id>/ עם התמונות.
3. עד שתעלי תמונה - האתר מציג "מקום שמור" יפה במקומה.
4. מצב עריכה (לתצוגה בלבד אצלך בדפדפן): פתחי index.html?edit - יופיע כפתור העלאה על כל תמונה.
   התמונות נשמרות רק בדפדפן שלך, כדי להציג ללקוחות יש לשמור אותן בתיקיות כאן.
המלצה: JPG בגודל עד ~400KB לתמונה (אפשר לדחוס ב-squoosh.app).

לפני/אחרי לכל פרויקט: שימי images/projects/<id>/before.jpg ו-after.jpg (אותה זווית צילום).
אם הקבצים חסרים יוצג מקום שמור. נתיב אחר: להוסיף לפרויקט ב-data.js שדה beforeAfter:{before:"...",after:"..."}.
